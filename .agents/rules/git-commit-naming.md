# Git Commit Naming Rule

Whenever making a git commit for this repository on GitHub:
1. Always include the exact date and time (timestamp) of when the commit was created in the commit message.
2. Example format:
   `git commit -m "feat: [description] - YYYY-MM-DD HH:MM:SS"` (e.g. `2026-09-01 21:01:50`).
