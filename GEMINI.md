# Workspace Guidelines & Rules

## Git Commit Protocol
Whenever making a git commit for this repository on GitHub:
- Always include the exact date and time (timestamp) of when the commit was created in the commit message.
- Example format: `git commit -m "feat: [description] - YYYY-MM-DD HH:MM:SS"` (e.g. `2026-09-01 21:01:52`).
